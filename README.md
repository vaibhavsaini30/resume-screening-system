# FitScore AI – Resume-to-Job Matching & Candidate Ranking System

A complete end-to-end machine learning and Flask web application that compares candidate resumes (`.pdf` and `.docx`) against custom job descriptions, predicts continuous `0–100` suitability scores, classifies suitability categories, ranks applicants in descending order, and explains matched/missing skills and experience alignment.

---

## Features

- **Home & SaaS Landing Page:** Clean, responsive interface explaining AI resume analysis, candidate ranking, skill-gap detection, and suitability scoring.
- **Custom Job Description & Multi-Resume Screening:** Supports single or batch `.pdf` and `.docx` uploads with drag-and-drop, individual file removal, client/server validation, and safe temporary-directory cleanup.
- **Exact Phase 2 & 3 ML Integration:**
  - `CatBoost Regressor` (`resume_screening_model.pkl`) predicts continuous `0–100` suitability scores.
  - `Logistic Regression (Balanced)` (`resume_classification_model.pkl`) independently predicts one of five categories (`Very Poor`, `Poor`, `Moderate`, `Good`, `Excellent`).
  - Reuses the fitted Phase 2 `TfidfVectorizer`, `SKILL_SYNONYMS` normalization dictionary, and exact `22`-feature engineering pipeline.
- **Ranking Dashboard & Analytics:** Searchable, filterable candidate ranking table, CSV export, Chart.js analytics (score comparison, category distribution, score distribution, required skill match comparison), and per-candidate detail pages with grounded explanations.
- **Session Isolation & Privacy:** Results are scoped to each user's active screening session so separate job descriptions never mix, and uploaded files are deleted immediately after processing.

---

## Technology Stack

- **Machine Learning & Data:** Python, Pandas, NumPy, Scikit-learn, CatBoost, XGBoost, SciPy, Joblib
- **Document Extraction:** `pypdf` (PDF), `python-docx` (DOCX)
- **Web Backend:** Flask (`app.py`, `screening_engine.py`)
- **Frontend:** HTML5, Custom CSS3, Vanilla JavaScript, Chart.js, Lucide Icons

## Installation & How to Run Locally

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Verify model artifacts exist:**
   Ensure `resume_screening_model.pkl` and `resume_classification_model.pkl` are present in the project root (generated by running Phase 2 in `Resume_Screening_System.ipynb`).

3. **Start the Flask application:**
   ```bash
   python app.py
   ```

4. **Open in your browser:**
   Navigate to `http://127.0.0.1:5000`

## Deploy on Render (Free Web Service via GitHub)

This repository includes `render.yaml`, `Procfile`, and `requirements.txt` configured for Render:

1. Push this project folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Deploy FitScore AI"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo>.git
   git push -u origin main
   ```
2. Sign in to [Render](https://render.com) → click **New +** → **Blueprint** (to auto-detect `render.yaml`) or **Web Service** and connect your GitHub repository.
3. Confirm settings:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn --workers 1 --threads 4 --timeout 120 --bind 0.0.0.0:$PORT app:app`
   - **Health Check Path:** `/health`
4. Click **Deploy Web Service** — once live, open your `https://<your-app>.onrender.com` URL.

## Supported Resume Formats & Limitations

- **Supported Formats:** `.pdf` (selectable text) and `.docx` (paragraphs and tables).
- **Limitations:**
  - Scanned/image-only PDFs without selectable text cannot be parsed without OCR and are flagged clearly to the user.
  - Both models were trained on a synthetic dataset with a heuristic `0–100` target rather than human recruiter labels, so scores serve as decision-support indicators rather than hiring guarantees.
  - Text-based extraction of years of experience, education, projects, and certifications relies on common resume phrasing and section headings.
